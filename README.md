## Приклад виконання (з датасетом "Iris")

Цей приклад допоможе вам зрозуміти, як виконати завдання.

### 1. Імпорт бібліотек та завантаження даних

```python
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
from ucimlrepo import fetch_ucirepo

# Завантаження даних (ID 53 - Iris)
iris = fetch_ucirepo(id=53)
X = iris.data.features
y = iris.data.targets
iris_df = pd.concat([X, y], axis=1)

# Надання стовпцям зрозумілих імен
iris_df.columns = ['sepal_length', 'sepal_width', 'petal_length', 'petal_width', 'species']
```

### 2. Аналіз даних

```python
# Виведення метаданих та інформації про змінні
print("Метадані:")
print(iris.metadata)
print("\nІнформація про змінні:")
print(iris.variables)

# Виведення перших 5 рядків та статистики
print("\nПерші 5 рядків датасету:")
print(iris_df.head())
print("\nОписова статистика:")
print(iris_df.describe())
```

### 3. Побудова та збереження графіків

**Гістограма:**

```python
plt.figure(figsize=(8, 6))
sns.histplot(iris_df["sepal_length"], bins=20, kde=True)
plt.title("Розподіл довжини чашолистків (Sepal Length)")
plt.xlabel("Довжина (см)")
plt.ylabel("Частота")
plt.savefig("histogram_example.png")
```

**Діаграма розсіювання:**

```python
plt.figure(figsize=(8, 6))
sns.scatterplot(x="sepal_length", y="sepal_width", hue="species", data=iris_df)
plt.title("Залежність між довжиною та шириною чашолистків")
plt.xlabel("Довжина (см)")
plt.ylabel("Ширина (см)")
plt.legend()
plt.savefig("scatterplot_example.png")
```

**Теплова карта кореляцій:**

```python
plt.figure(figsize=(8, 6))
# numeric_only=True необхідно для ігнорування нечислових стовпців
correlation_matrix = iris_df.corr(numeric_only=True)
sns.heatmap(correlation_matrix, annot=True, cmap="coolwarm")
plt.title("Теплова карта кореляцій")
plt.savefig("heatmap_example.png")
plt.show()
```
